## 👨‍💻 POUR LES CRÉATEURS DE CONTENU

### Étape 1 : Inscription
1. **Cliquez sur "Commencer maintenant"** ou **"S'inscrire"** dans la navigation
2. **Choisissez votre profil** : Créateur
3. **Remplissez le formulaire** :
   - Nom complet
   - Email professionnel
   - Numéro de téléphone
   - Mot de passe (8 caractères minimum)
   - Confirmation du mot de passe
4. **Cliquez sur "Créer mon compte"**
5. **Vérifiez votre email** (lien envoyé automatiquement)

### Étape 2 : Connexion
1. **Cliquez sur "Connexion"** dans la navigation
2. **Entrez votre email et mot de passe**
3. **Cliquez sur "se connecter"**
4. **Mot de passe oublié ?** Cliquez sur "Oublié ?" pour le réinitialiser

### Étape 3 : Configuration du profil créateur
Après connexion, vous accédez à votre tableau de bord :

#### 📋 Tableau de bord créateur
- **Menu latéral gauche** pour naviguer
- **Statistiques principales** : revenus, projets, collaborations
- **Actions rapides** : nouveau projet, modifier profil

#### 🎯 Complétez votre profil
1. **Cliquez sur "Profil"** dans le menu
2. **Ajoutez vos informations** :
   - Photo de profil
   - Bio et description
   - Spécialités (mode, beauté, tech, etc.)
   - Tarifs par type de contenu
   - Réseaux sociaux
3. **Cliquez sur "Sauvegarder"**

#### 📱 Configuration des réseaux sociaux
1. **Allez dans "Réseaux sociaux"** 
2. **Connectez vos comptes** :
   - Instagram
   - TikTok
   - YouTube
   - Autres plateformes
3. **Autorisez l'accès** pour analyser vos performances

#### 💰 Définir vos tarifs
1. **Cliquez sur "Tarifs"**
2. **Fixez vos prix** par type de contenu :
   - Story Instagram : X€
   - Vidéo YouTube : X€
   - Post TikTok : X€
3. **Activez la disponibilité**

### Étape 4 : Trouver des collaborations
#### 📊 Votre tableau de bord
- **Projets recommandés** : basés sur votre profil
- **Invitations reçues** : marques qui vous contactent
- **Projets en cours** : collaborations actives

#### 🔍 Rechercher des projets
1. **Cliquez sur "Catalogue"**
2. **Filtrez par** :
   - Type de contenu
   - Budget
   - Marque
   - Délai
3. **Postulez aux projets** qui vous intéressent

#### 📝 Soumettre une candidature
1. **Cliquez sur un projet**
2. **Lisez le brief** attentivement
3. **Cliquez sur "Postuler"**
4. **Rédigez votre proposition** :
   - Pourquoi vous êtes le/la parfait(e) candidat(e)
   - Votre idée créative
   - Votre tarif
   - Délai de livraison
5. **Envoyez votre candidature**

### Étape 5 : Gérer les projets
#### ✅ Projets acceptés
1. **Dans "Projets en cours"**
2. **Cliquez sur le projet**
3. **Consultez le brief détaillé**
4. **Téléchargez les éléments de la marque**
5. **Créez votre contenu**
6. **Uploadez votre travail**
7. **Attendez la validation**

#### 💸 Paiement
1. **Après validation du client**
2. **Le paiement est libéré automatiquement**
3. **Consultez vos revenus** dans "Statistiques"
4. **Demandez le virement** quand vous le souhaitez

## 🏢 POUR LES MARQUES ET ENTREPRISES

### Étape 1 : Inscription
1. **Cliquez sur "Commencer maintenant"** ou **"S'inscrire"**
2. **Choisissez votre profil** : Marque
3. **Remplissez le formulaire d'entreprise** :
   - Nom de l'entreprise
   - Email professionnel
   - Numéro de téléphone
   - Mot de passe
   - Confirmation du mot de passe
4. **Cliquez sur "Créer mon compte"**
5. **Vérifiez votre email**

### Étape 2 : Connexion
1. **Cliquez sur "Connexion"**
2. **Entrez vos identifiants**
3. **Accédez à votre tableau de bord marque**

### Étape 3 : Configuration du profil entreprise
#### 🏢 Informations de l'entreprise
1. **Allez dans "Profil"**
2. **Complétez les informations** :
   - Logo de l'entreprise
   - Description et activités
   - Secteur d'activité
   - Taille de l'entreprise
   - Site web
3. **Sauvegardez**

#### 💳 Configuration du paiement
1. **Allez dans "Paiement"**
2. **Ajoutez votre carte bancaire**
3. **Configurez le plafond de dépenses**
4. **Activez les paiements automatiques**

### Étape 4 : Créer une campagne
#### 📋 Nouveau projet
1. **Cliquez sur "Nouvelle campagne"**
2. **Remplissez le brief** :
   - **Titre du projet**
   - **Description détaillée**
   - **Objectifs** (notoriété, ventes, etc.)
   - **Type de contenu** souhaité
   - **Budget total**
   - **Délai de livraison**
   - **Instructions spécifiques**

#### 🎯 Sélection des créateurs
1. **Définissez votre cible** :
   - Âge, genre, localisation
   - Centres d'intérêt
   - Taille d'audience minimale
   - Style de contenu
2. **Lancez la recherche**
3. **Consultez les profils recommandés**
4. **Sélectionnez les créateurs** qui vous intéressent

### Étape 5 : Gestion des collaborations
#### 📊 Tableau de bord
- **Campagnes actives** : en cours actuellement
- **Candidatures reçues** : créateurs intéressés
- **Projets terminés** : historique
- **Dépenses totales** : suivi budgétaire

#### ✅ Validation des contenus
1. **Dans "Projets en cours"**
2. **Cliquez sur le projet**
3. **Consultez les contenus soumis**
4. **Acceptez ou demandez des modifications**
5. **Validez pour débloquer le paiement**

#### 📈 Analyse des performances
1. **Allez dans "Statistiques"**
2. **Consultez les métriques** :
   - Taux d'engagement
   - Portée des publications
   - Retour sur investissement
   - Performance par créateur

## 🆘 ASSISTANCE ET DÉPANNAGE

### Problèmes fréquents
#### 🔐 Mot de passe oublié
1. **Cliquez sur "Oublié ?"** sur la page de connexion
2. **Entrez votre email**
3. **Recevez un lien de réinitialisation**
4. **Créez un nouveau mot de passe**

#### 📧 Email non reçu
1. **Vérifiez vos spams/promotions**
2. **Attendez 5-10 minutes**
3. **Demandez un nouvel envoi** si nécessaire

#### 🚫 Connexion impossible
1. **Vérifiez votre email et mot de passe**
2. **Réinitialisez votre mot de passe**
3. **Contactez le support** si le problème persiste

#### 📱 Problèmes d'affichage mobile
1. **Rafraîchissez la page**
2. **Videz le cache de votre navigateur**
3. **Utilisez la dernière version de votre navigateur**

### Contact support
- **Email** : support@woutty.com
- **Téléphone** : disponible dans le footer du site
- **Chat en direct** : icône en bas à droite du site
- **FAQ** : section questions/réponses en bas de page
